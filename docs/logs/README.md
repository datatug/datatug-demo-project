# Northwind order 11039 investigation fixture

These logs are **synthetic**. They were written for a DataTug demonstration; DemoDB and Northwind did not produce them. The business record is real in the pinned DemoDB Northwind SQLite fixture: `Orders.OrderID=11039`, `CustomerID=LINOD`, `ShipVia=2`, and `ShippedDate IS NULL`. The `Shippers` table maps `2` to United Package. Four `Order Details` rows belong to this order.

The JSONL file carries the complete cross-service timeline, two unrelated-order noise records, one bad timestamp and one malformed JSON line. The text file exercises multiline error retention. Both are small, versioned inputs for direct file reads; no database snapshot of logs is created.

| Claim | Database evidence | Synthetic log evidence |
| --- | --- | --- |
| The order had not shipped | `Orders(11039).ShippedDate IS NULL` | `orders-api` deferred update at 09:13:06Z |
| The chosen carrier was United Package | `Orders(11039).ShipVia=2`, `Shippers(2).CompanyName` | `shipping-worker` label request at 09:13:04Z |
| The carrier call failed | No claim about historical carrier behavior | `carrier-gateway` HTTP 503 at 09:13:05Z, multiline stack in text source |
| The immediate blocking cause in this synthetic run was no retry | No retry setting in Northwind; do not infer one | `shipping-worker` WARN at 09:13:05.300Z reports `retry_budget=0` and terminal classification |

The conclusion is specific to the synthetic run: a retryable carrier failure was treated as terminal, and the shipping update was deferred. The database alone does not establish why the order did not ship historically.

## Reproduce and inspect

Use the [local demo guide](guide.md) to run the direct OVDB source and DataTug
app. The [standalone HTML walkthrough](walkthrough.html) is generated by
`python3 scripts/build-logs-walkthrough.py` while the local source runs. It
embeds the actual OVDB responses for these committed fixtures and needs no
network or server after generation. It is an interactive explanation, not a
screenshot of the product.
