How the working slice is wired

The file adapter scans a bounded allowed file on each query and exposes a DALGO collection. A programmatic OVDB mount serves the existing discovery and query protocol. DataTug maps the ordinary result fields into its log evidence grid. Nothing is copied into a log database.

Versioned JSONL + text files → dalgo2logs → DALGO → Unchanged OVDB HTTP → DataTug evidence grid
