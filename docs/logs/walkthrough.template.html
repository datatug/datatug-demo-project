    How the working slice is wired

    The file adapter scans a bounded allowed file on each query and exposes a DALGO collection. A programmatic OVDB mount serves the existing discovery and query protocol. DataTug uses an explicit field mapping and timeline presentation. Nothing is copied into a log database.

    Versioned JSONL + text files → dalgo2logs → DALGO → Unchanged OVDB HTTP → DataTug timeline

    Google Cloud Logging is a second direct-read adapter with a fixed project and bounded time window. Hosted access to a user's own project requires separate server-side authorization.
